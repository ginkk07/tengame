# Ozeti v95 全圖細節資料

資料來源：N4 Lab / NCONNECTOR WARDOGS 地圖瀏覽器，https://wardogs.n4lab.dev/?map=ozeti&mode=view ，素材來源 https://wd-maps-assets.n4lab.dev/ 。更新日期：2026-10-07。原作者權利保留。

## 全圖近景

所有地區採用相同的近景模型距離規則，原始建築與物件配置都接入 world HQ 模型庫，保留 129,588 個有效構件。v94 用於世界 HQ 的細胞包省略了 10,307 個內部構件，v95 改從完整 world base 配置載入，因此這些構件也能顯示。原始配置中的零縮放停用項目不渲染。

中央仍保留 57,064 個有效建築及裝飾構件、48,759 個 HQ 植被配置和原始城市地面紋理。

world-vegetation-hq-v95.pack 是按原始模型名稱匹配後製作的 HQ 模型庫，共 73 個模型。Ozeti 外圍實際使用其中 61 個、全圖與中央合計使用 68 個模型；均已找到同名 HQ 幾何。部分模型取自原站另兩個區域的植被包，只重用同名模型，配置仍使用 Ozeti 原始資料。沒有將其他區域的城市配置疊進 Ozeti。

森林遠景包圍輪廓改用 HQ 真實尺寸，近景使用原始樹幹、枝葉、樹冠、灌木和倒木構件，並增加樹冠陰影。植物位置均來自原站。

## 地形與材質

256 片原始高度資料，各含 513 × 513 個樣本，共 67,371,264 個樣本（包含相鄰片重疊邊界）。取樣間距 1.9921875 m，編碼高度量化 0.25 m；量化間距不代表絕對高度準確度。近景按位置載入 3 × 3 範圍，標準／細緻使用 2 m 左右網格，流暢使用約 4 m 網格，遠景使用約 16 m 網格。

原始高度無損保存在 height-tiles/*.u16.gz。執行時對比至少五個鄰點相差超過 16 m 的孤立尖峰以鄰域中值抑制，連續崖面保留。原始資料不因此修改。地形接縫增加側裙，路面在高度載入後重新貼合地形。

外圍沒有原站完整的城市式地面影像，因此採原始地表分類，並在材質中重用中央地面紋理的細節；這部分是按中央外觀補充的材質，並非整張地圖的原始攝影貼圖。道路中心線沿用原站，增加長向／橫向分段和柔和路肩，路色與中央風格一致。

## 座標與格式

座標與 WDGP v1 格式延續 NATIVE-DATA-v94.md。site-local 座標以公尺表示、Y 向上、Z 向南。原站四點校準最大殘差約 0.88 m。場景轉換為：

```
scale = 1.255248129046039
worldX = nativeX * scale + (10034.76529503742 - 8189) * 1.25
worldZ = nativeZ * scale + (8191 - 6335.6928) * 1.25
worldY = (nativeY + 100) * scale
```

高度 +100 m 是顯示基準，HUD 高度並非海拔。矩陣、負縮放反射和模型顏色均依原始資料處理。

## 驗證

完整世界配置的所有建築／物件模型均有 HQ 對應，实际建立 129,588 個配置並核對有效配置計數。外圍全部 61 個植被模型有 HQ 對應。原始新增植被包均對照原站 manifest 的 SHA-256，派生素材與全圖高度另記錄校驗碼。

檢查 51,998 個 typed-array view 界線、幾何反射、座標往返、高度取樣、細緻地形載入與遠近切換、道路及構件碰撞。孤立高度尖峰抑制另檢查尖峰移除與連續崖面保留。

模型高細節並不等同遊戲的所有材質、動畫與特效；此版本以原站公開幾何及配置為基礎。遠景仍使用較低細節，所有地區在拉近後使用相同規則。
